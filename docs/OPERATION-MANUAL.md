## Mission 1：通訊配對（20 分）

**要做的**：ROV 自己連上塔、自己把一串字抓回來，唸給裁判聽。筆電只負責顯示。

> 大會規定**只能用 ESP32**，不准用手機或電腦瀏覽器；用 HTTP GET。
> 筆電端沒有安裝任何網路庫，想違規也做不到。

### 一、開操作台

在 repo 根目錄下：

```powershell
python host\console.py
```

等左上角出現**綠燈 ● LINK**。

### 二、設定位址

**Wi-Fi 名稱和密碼已經編譯在韌體裡**，不用設：

```
CityUHK_UR_Fall-Training
```

**只有塔的位址要設**——IP 當天才公布。

1. **按手柄上的 X** —— 進 WiFi 模式
2. **按鍵盤上的 T** —— 左上角出現 `>`，右下角同時列出可用的指令

   （**視窗不能複製貼上**，指令要自己打。所以它會印在螢幕上讓你照著打。）

3. 打（換成大會給的 IP）：

   ```
   P url <IP>:8080
   ```

4. 按 **Enter**
5. 看到這行就對了：

   ```
   OK P url = http://10.x.x.x:8080
   ```

   （少打 `http://` 沒關係，程式會補，並把補完的結果印出來）

> ⚠️ **port 一定要打 8080。** 只寫 IP 的話程式會去連 80 埠，
> 而錯誤訊息不會告訴你是 port 的問題。

> **位址存在板子裡，斷電和重燒都不會掉。** 一天只要設一次。
> 進場前按 `T` 打 `G url` 確認一次，大會可能換。
>
> ⚠️ **`R` 被擋掉了**——它會把校準過的配平、中立位一起清掉。

### 三、看資料

設完等 **2 秒**，板子會自己抓一次。看左下角，三行都要對：

```
wifi CONNECTED
http 200
DATA [Congratulations!!! This is the WiFi API task message for the fall training.]
```

把 `DATA` 那行唸給裁判聽。

### 連不上時：按 `L` 看得到什麼

按 `T` 打 **`L`** 再按 Enter，板子會掃描並把**它實際看得到的 Wi-Fi** 列在左下角
（最強的排前面）：

```
nets   -42 ch6  大會公布的 SSID
       -58 ch1  別的網路
       -66 ch11 別的網路
```

**這一步決定你接下來該做什麼，不要跳過。**

| 列表裡有**大會公布的 SSID** 嗎 | 意思 | 怎麼做 |
|---|---|---|
| **有**，而且訊號不差（−70 以內） | 訊號沒問題，是**密碼**或設定 | `P pass <正確密碼>` → `W` |
| **有**，但訊號很差（−85 之類） | 太遠 | 把 ROV 移近，或找主辦 |
| **沒有** | **板子根本掃不到那個網路** | 改密碼沒有用。**去找主辦**——很可能是 5 GHz 或還沒開 |

> **`wifi` 那行也會直接告訴你原因**：`NO_SSID`（掃不到）、`BAD_PASS`（密碼錯）、
> `CONNECTING`（還在試）、`LOST`（斷了）。

### 沒成功時

| 看到 | 怎麼辦 |
|---|---|
| `wifi NO_SSID` | 掃不到那個網路。按 `L` 確認，然後找主辦 |
| `wifi BAD_PASS` | 密碼錯了。`P pass <正確的>` 再 `W` |
| `wifi CONNECTING` 超過 30 秒 | 還在試。按 `L` 看板子掃到什麼 |
| `wifi LOST` 一直跳 | **不要重啟板子。** 打 `P wifiRetryMs 30000` |
| `EV url not set` | 位址沒設，回第二步 |
| `http` 是負數 | 打 `G url`——**先確認 port 有沒有打進去** |
| `http 200` 但 `DATA` 空的 | 等下一次輪詢，或按手柄上的 X 出去再進來 |

### 要換一個 Wi-Fi

```
P ssid <新的名字>
P pass <新的密碼>
```

**不用再打 `W`**——改 ssid 或密碼會自己重新連線。

名字**可以有空格、大小寫、連字號**，照打就好。

## Mission 2.1：AprilTag 掃描（40 分）

**要做的**：掃描三個 AprilTag，把裁判指定的邏輯（最大 or 最小）算出來的那個 ID 報給裁判。
**邏輯選錯、或沒把答案顯示出來 = 0 分。**

### 一、進模式

1. **按手柄上的 A**
2. 左下角出現 `SELECTION LOGIC NOT SET`

### 二、選邏輯（裁判當天唸給你）

- **按鍵盤上的 L** = 取最大
- **按鍵盤上的 M** = 取最小

> **沒選之前，按手柄上的 RB 不會有反應。** 猜錯是零分，所以不給預設值。

### 三、掃描（重複三次）

1. 把 ROV 開到三個 tag 都看得到的位置
2. **按手柄上的 RB** —— 拍約 0.3 秒
3. 左下角 `captures` 加一、`ids` 多一個號碼

```
MODE  AprilTag
logic    largest   (L)
captures 2/3
ids      [3, 7]
RESULT   7
```

### 四、報答案

唸 `RESULT` 那行。拍到第三次會多一個 `DONE`。

> **每拍到一次就自動存一張截圖**到 `host/snapshots/`（檔名 `apriltag-日期-時間.png`）。
> 那是**整張操作台畫面**，左下角帶著 `ids` 和 `RESULT`——裁判要確認時直接開給他看。
> 沒拍到 tag 的那一次不會存。

### 三個一定要記住的

**① `ids` 才是重點，不是 `captures`。**
三次都拍到同一個 tag，`ids` 只有一個號碼，答案是錯的。
**要拍到三個不同的 tag**，不是拍滿三次。

**② `RESULT` 從第一次拍到就開始算。** 兩次湊齊三個 ID 就不用硬拍第三次。

**③ 按手柄上的 A 出去再進來會全部重來**，包括邏輯——裁判每次重新告知。

### 沒成功時

| 看到 | 怎麼辦 |
|---|---|
| 按手柄上的 RB 沒反應 | 還沒選邏輯 |
| `captures` 沒有加 | 那一拍沒看到 tag，**不佔次數** |
| `ids` 只有一兩個號碼 | 拍到重複的 tag 了，見上面① |
| 想重來 | 按**鍵盤上的 R**——清掉結果，**保留邏輯** |

## Mission 2.2：艙室停靠（20 分）

把 ROV 開進正確的艙室，不要碰到任何東西。**純手動，程式不參與。**

| 結果 | 分數 |
|---|---|
| 順利開進去，全程沒碰到 | 20 |
| 開進正確的艙室，但碰到了（含纜線、機械臂、機架） | 10 |
| 開錯艙室、沒開完、或放棄 | 0 |

## Mission 3：循線（30 分）

沿著池底的黑線開，依序通過檢查點。**純手動。**

| 到達 | 分數 |
|---|---|
| 通過 Checkpoint 1 | 10 |
| 通過 Checkpoint 2 | 10 |
| 到達終點線 | 30 |

**只有最高的那個算，不累加。** 走到終點就是 30 分。

> ⚠️ **程式完全沒有循線功能**——沒有偵測黑線、沒有輔助。只能手動開。
> 手冊允許軟體輔助（含人工操作的 PID），要加得另外寫。

## Mission 4：物件回收（40 分）

用鉤子把池底的目標物勾起來，帶回起點放開。**純手動。**

| 結果 | 分數 |
|---|---|
| 勾住 → 帶回起點 → 放開 | 40 |
| 勾住後**離地 3 秒** | 20 |
| 只碰到、沒勾住 | 0 |

**中途掉了**：已經達成過 3 秒離地就保留 20 分；還沒滿 3 秒就掉了 = 0 分。

## Mission 5：顏色桿辨識與擊打（50 分）

找出紅、黃、藍三根桿子，把它們的球打下來。**擊打是純手動**，程式只負責辨識顏色。

| 結果 | 分數 |
|---|---|
| 每打下一根桿子的球 | 10（最多 30） |
| **完全照裁判給的順序**打完三根 | **+20** |

### 一、進模式

**按手柄上的 B**，左下角出現 `MODE  Colour`。

### 二、校準（換場地才要做）

1. 把**滑鼠游標移到純桿身**上（不要指邊緣或池底）
2. 按鍵盤上的 **`1`** = 紅、**`2`** = 黃、**`3`** = 藍
3. 終端印出 `R calibrated from the pointer` 就成功，會存檔

> 取樣範圍是游標周圍 31×31 像素，**準星要對準桿身正中**。指偏了不會報錯。

### 三、辨識

1. 把**游標移到桿子上**——畫面會有一枚**青色十字準星**
2. **按手柄上的 RB**
3. 畫面**最下方**用該顏色的字印出答案：

   ```
   color recognition = RED
   ```

> 瞄好之後手移到手柄上按 RB，程式用的還是你最後指的那一點。

### 四、打下來

照裁判喊的順序，一根一根打。

> **每次辨識出顏色就自動存一張截圖**到 `host/snapshots/`（檔名 `colour-日期-時間.png`）。
> 畫面底部那行 `color recognition = RED` 會一起入鏡——裁判要確認時直接開給他看。

> ⚠️ **順序自己記。** 裁判喊的每次可能不同，程式沒有地方輸入、畫面也不會顯示。
> **裁判喊完立刻寫下來。**

### 沒成功時

| 看到 | 怎麼辦 |
|---|---|
| 畫面底部沒有答案 | 瞄準桿身正中，再按一次 |
| `too few coloured pixels` | 指到灰色池底了 |
| `sample is too colour-mixed` | 指到兩根桿子中間的接縫了 |
| 答案顏色不對 | 重新校準（回步驟二） |
| 按 RB 沒反應 | 游標要先在畫面上出現過一次 |

> **這是取樣，不是偵測。** **指到藍色池底油漆就會回報 BLUE。**

# 附錄：用序列埠監視器送指令

**平時不需要。** Mission 1 的位址在操作台裡**按 `T`** 就能打。

這個附錄是**備用路線**——操作台開不起來，或要看板子從開機以來的完整訊息時才用。

## 板子指令不是 shell 指令

| | 在哪裡打 | 例子 |
|---|---|---|
| Shell 指令 | 終端機 | `pio run -d firmware\ESP32 -t upload` |
| **板子指令** | **操作台裡按 `T`**，或序列埠監視器 | `P url …`、`G ssid` |

## 找出板子在哪個 COM 埠

```powershell
pio device list
```

```
COM4 | 透過藍牙連結的標準序列 (COM4)
COM5 | USB Serial Port (COM5)
```

**看描述，不要看編號。**

| 描述 | 是不是板子 |
|---|---|
| `USB Serial Port` | ✅ FTDI |
| `USB-SERIAL CH340` | ✅ CH340 |
| `Silicon Labs CP210x` | ✅ CP210x |
| `USB Serial Device` | ✅ ESP32 自己的 USB |
| `透過藍牙連結的標準序列`／`Bluetooth` | ❌ 電腦的藍牙 |
| `Communications Port` | ❌ 主機板內建 |

> ⚠️ **整排都是藍牙很常見。** 選錯的話打什麼都沒反應，而且不會報錯。

## 開監視器

| 方法 | 怎麼做 |
|---|---|
| **A. VS Code PlatformIO**（推薦） | PlatformIO 圖示 → `PROJECT TASKS` → **`Monitor`**。自動找埠、自動 115200 |
| **B. 命令列** | `pio device monitor -d firmware\ESP32` |
| **C. `pio` 被擋掉時** | `python -m serial.tools.miniterm COM5 115200` |

`-d firmware\ESP32` 是告訴 `pio` 專案在哪。**不能省**——省掉的話它找不到
`platformio.ini`，鮑率會變成預設的 **9600**，讀出來全是亂碼。

埠抓錯了就明講：

```powershell
pio device monitor -d firmware\ESP32 --port COM5
```

## 送指令

打開後畫面會一直跳 `JOY ...`——正常，板子每 50 ms 回報一次。**直接打字**，整行打完按 Enter：

```
P url 192.168.4.1:8080
```

回 `OK P url = http://192.168.4.1:8080` 才算成功。

| 指令 | 作用 |
|---|---|
| `L` | **掃描並列出看得到的 Wi-Fi** |
| `G ssid` / `G url` | 看現在用什麼 |
| `G` | 列出所有參數 |
| `S` | 看狀態（Wi-Fi、IP、HTTP 碼） |
| `P url 192.168.4.1:8080` | 設塔的位址 |
| `P ssid 名稱` / `P pass 密碼` | 設 Wi-Fi（名稱有空格也可以） |
| `W` / `F` | 立刻重連 / 立刻抓一次 |
| `B` | 重啟板子 |

> ⚠️ **不要送 `R`**——它會把 `neutral`、`trimL`、`trimR`、`trimV`、`fsMs`
> 連同 Wi-Fi 一起清掉。要改哪一項就 `P` 哪一項。

## 離開

**`Ctrl+C`**，沒反應就 **`Ctrl+]`**。

## 三個坑

1. **`&&` 不能用**——PowerShell 5.1 不支援。一次打一行。<br>
   `The token '&&' is not a valid statement separator in this version.`
2. **`pio` 找不到就用 `python -m platformio`。**
3. **`-d firmware\ESP32` 不能省**——省掉會變成 9600 鮑率，全是亂碼。

## 出問題時

| 現象 | 原因 |
|---|---|
| 打指令完全沒反應 | 埠選錯了，多半是藍牙那個 |
| `cannot open COM5` | 埠被 `console.py`、另一個監視器、或 Arduino IDE 佔著 |
| 畫面全是亂碼 | 鮑率不是 115200 |
| `pio` 一執行就被擋 | Windows 應用程式控制政策。改用方法 A 或 C |

> ⚠️ **監視器和 `console.py` 不能同時開。先關監視器，再開 `console.py`。**
