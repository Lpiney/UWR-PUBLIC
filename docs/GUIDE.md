# UWR ROV 操作指南

從零到能動，照順序做。每一步都有驗證方法，過了再往下走。

---

## 0. 系統長什麼樣

```
Xbox 手柄 ──USB──> 筆電 ──序列埠──> ESP32 ──PWM──> 兩個電調 ──> 推進器
   │                │                  │
   │                │                  └── Wi-Fi + HTTP（Mission 1，板子自己做）
   │                └── 攝影機、畫面、辨識
   └── 所有按鍵都在這裡讀
```

**手柄和影像在筆電，馬達和 Mission 1 在板子。** 筆電的程式當掉不會讓 ROV 失控，
因為兩道安全防線都在板子裡。

---

## 1. 準備

### 硬體

| 東西 | 備註 |
|---|---|
| ESP32-S3 | N16R8（16 MB）或 N8R8（8 MB） |
| 兩個電調 + 兩個推進器 | 電調另外要接動力電池 |
| Xbox 手柄 + USB 線 | 有線最省事 |
| 攝影機 | 筆電內建的就夠 |
| 杜邦線 | 電調**地線必須接回 ESP32 的 GND** |

### 接線

| 電調細線 | 接到 |
|---|---|
| 訊號（白／橙） | 左 **GPIO4**、右 **GPIO5** |
| 地（黑／棕） | GND |
| 電源（紅，BEC 5V） | **留空不接** |

### 裝軟體

**Windows**

```bash
python -m pip install -r host\requirements.txt
```

Python 用 python.org 的 3.11，安裝時勾「Add python.exe to PATH」。
PlatformIO 用 VS Code 的擴充（「開啟資料夾」打開 `firmware\ESP32`），
或用命令列 `python -m pip install platformio`。

**macOS / Linux**

```bash
python3 -m pip install -r host/requirements.txt
```

> `pip install` 要裝進**你實際拿來跑的那個 python**。機器上常有好幾個 python，
> 裝進一個、用另一個跑，是最常見的「我明明裝了啊」。

**驗證**

```bash
python3 host/pad_bridge.py --selftest
```

看到 `self test passed` 就對了。這一步不需要手柄、不需要板子。

## 2. 燒韌體

```bash
cd firmware/ESP32
pio run -t upload
```

| 板子 | 指令 |
|---|---|
| **N8R8**（8 MB，實驗室那塊） | `pio run -t upload` |
| **N16R8**（16 MB） | `pio run -e uwr-rov-16mb -t upload` |

不確定就先用預設值——8 MB 的設定在 16 MB 的板子上也能跑，只是用不到上面一半。
**反過來不行**，16 MB 的分割表燒進 8 MB 的晶片會做出開不了機的映像。

埠認不出來就明講：`pio run -t upload --upload-port COM5`（Windows）或
`--upload-port /dev/cu.usbserial-XXXX`（macOS）。

**驗證**：燒完打開序列埠監視器（115200），應該每 50 ms 刷一行 `JOY`。

## 3. 脫槳測試（第一次一定要做）

> **先拆槳。** 手邊留著電源開關。

1. 只給 ESP32 上 USB 電，**電調的動力電先不要接**
2. 跑 `python3 host/pad_bridge.py --show-input`，推左搖桿
   - 推上 → `Y` 要是**正**數
   - 推右 → `X` 要是**正**數
   - 不對的話記下來，先別往下走
3. 記下你按的鍵對應的編號（A / B / X / RB 各是幾號）
4. 接上電調動力電
5. 跑 `python3 host/console.py`
6. 畫面右下角會顯示 `Y Lock [LOCKED]`——安全鍵是 **Y**，此時是鎖著的。
   按一下 Y 解鎖，再輕推搖桿

**驗證**：兩個馬達都轉，而且方向正確。轉向反了就兩根相線對調。

## 4. 操作

```bash
python3 host/console.py
```

畫面：中間是攝影機，四角是狀態。

```
┌──────────────────────────────────────────────┐
│ ● LINK   UNLOCK        L 1718  ▓▓▓▓▓▓▓▓░░    │  左上 連線 + 安全鍵
│                        R 1282  ▓▓▓▓▓▓░░░░    │  右上 兩路輸出脈寬
│                    CAMERA                    │  中間 攝影機
│ MODE  AprilTag         A  AprilTag   [ON]    │  左下 目前任務
│ ID 07  dist 1.24 m     B  Colour     [  ]    │  右下 按鍵
│ CONF 0.93              X  WiFi       [  ]    │
│                        RB Lock       [LOCKED]│
└──────────────────────────────────────────────┘
```

| 按鍵 | 功能 |
|---|---|
| **A** | 切到 AprilTag 模式（Mission 2.1） |
| **B** | 切到顏色模式（Mission 5） |
| **X** | 切到 WiFi 模式（Mission 1） |
| **RB** | **拍一張**——在目前模式下辨識一次 |
| **Y** | 安全鍵（解鎖／上鎖） |

**A / B 只切模式，不做事。** 切過去之後畫面是即時預覽、不跑任何計算；**按 RB 才
辨識一次**，結果凍結在那一幀停住不跟著鏡頭飄；再按一次 RB 就重拍。

X 模式例外，它顯示的是板子主動回報的 Mission 1 狀態，不需要觸發。

再按一次 A / B 回到 Manual。**搖桿永遠都能驅動**，切任務不影響。

視窗裡按 `Q` 或 `Esc` 離開。

### 顏色模式：游標指哪就辨識哪（Mission 5）

```
按 B → 游標指著桿子 → 按 RB → 畫面底部出現 color recognition = RED
```

1. 按 **B** 進模式
2. 把**滑鼠游標移到要辨識的桿子上**。游標位置會有一枚**青色十字準星**標出來，
   那代表程式認為你在指哪裡
3. 按 **RB**，畫面正下方用**該顏色的字**印出答案：

   ```
                    ┌────────────────────────────┐
                    │  color recognition = RED   │
                    └────────────────────────────┘
   ```

**不凍結畫面**——你在瞄準的時候需要看得到即時影像。

**判定方式**：取游標周圍 15×15 像素，要求

- **至少四成是彩色**——灰色池底、白色反光會被排除
- **至少六成落在同一個顏色**——門檻設在明顯過半，是為了讓「指在兩根桿子的接縫上」
  回報「沒有答案」，而不是挑一個剛好多幾像素的顏色

不符合就顯示 `--`，終端也會說明原因。

> 這是**取樣**不是**偵測**：程式不判斷「那根桿子像不像桿子」，只看你指的那一塊
> 是什麼顏色。**指到藍色池底油漆就會回報 BLUE。** 答案的好壞取決於你瞄得準不準。

| 鍵 | 作用 |
|---|---|
| `C` | 跟 RB 一樣：辨識一次 |
| `1` `2` `3` | 游標指著純桿身按下去，校準紅／黃／藍（會存檔） |
| `N` | 操作員確認球已掉落，推進到下一個顏色 |
| `R` | 清掉答案 |
| `D` | 顯示顏色遮罩除錯視窗 |

顏色閾值**必須在真實泳池校準**，預設值只是起點。

> **校準也是指向式的**：游標指著桿子，按 `1`（紅）／`2`（黃）／`3`（藍）就好，
> 不用拖框、不會彈出第二個視窗。它取游標周圍 31×31 像素來算閾值。
>
> ⚠️ 這表示校準樣本比原本小。如果桿子很細或游標偏了，會得到一組不對的閾值——
> 按 `1`/`2`/`3` 之前先把準星對準杆身正中。

> **游標離開視窗位置會保留。** 瞄好之後手移到手柄上按 RB，程式用的還是你最後
> 指的那一點。

### AprilTag 的完整流程（Mission 2.1）

```
按 A → 選邏輯（L/M）→ 拍三次（RB）→ 看結果
```

1. 按 **A** 進模式。左下顯示 `SELECTION LOGIC NOT SET`
2. 裁判會告知要最大的還是最小的 ID：
   - 按 **L** = 最大的 ID（largest）
   - 按 **M** = 最小的 ID（smallest）

   **沒選之前 RB 不會動作。** 猜錯邏輯是零分，不能讓它默默用一個預設值。
3. 每按一次 **RB** 拍一次（約 0.3 秒），把確認到的 ID 併進集合
4. 左下角即時更新：

   ```
   MODE  AprilTag
   logic    largest  (L)
   captures 2/3
   ids      [3, 7]
   RESULT   7
   ```

5. 拍到第三次標 `DONE`。**結果從第一次拍到就開始算**——如果兩次就湊齊三個 ID，
   不用硬拍第三次。
6. 按 **R** 重新掃（保留邏輯）。按 **A** 回 Manual 再進來則**全部重來**，
   包含邏輯（因為每次上場裁判都會重新告知）

**畫面不會凍結。** 掃描的時候你還是要操縱 ROV，凍結的畫面沒有用。框只在拍照
那一瞬間畫出來，收到什麼 ID 留在左下面板。

**空拍不算次數。** 沒看到任何 tag 的那一拍不會佔用三次配額。

> ⚠️ **三次拍照 ≠ 三個不同的 tag。** 可能三次都拍到同一個，也可能一次就拍到三個。
> 真正決定結果的是 **`ids` 那個集合**，不是次數。拍完看一下集合裡有幾個，
> 不對就按 R 重來。

### 各拍幾幀

| | 拍多久 | 確認條件 |
|---|---|---|
| AprilTag | 約 0.3 秒 | 同一 ID 要在 ≥2 幀出現 |
| 顏色 | 約 1 秒 | 候選要在 ≥60% 的幀出現，且最後一幀仍看得到 |

AprilTag 取兩幀而不是一幀，是因為單幀被水波晃糊就整個認不出來。

> 框選 ROI 或校準時會彈出選取視窗，那幾秒鐘驅動迴圈會暫停，板子的斷流保護
> 會把馬達送回中立。這是安全的方向——你在框框的時候本來就沒在操縱。

### 沒有硬體也能看畫面

```bash
python3 host/console.py --synthetic    # 沒有攝影機
python3 host/console.py --no-serial    # 沒有板子
```

## 5. 安全規則（必讀）

馬達沒有「解鎖後就一直是活的」這回事，四道閘都在板子裡：

| 閘 | 行為 |
|---|---|
| 安全鍵 | 預設鎖著，按一下解鎖。**手柄掉線自動重新鎖上** |
| 斷流保護 | 200 ms 沒收到指令就強制回中立 |
| 開機預熱 | 上電後 3 秒內不理輸入 |
| 油門限速 | 脈寬每毫秒最多變 2 µs，不會啪一下滿油門 |

**四條一定要記住的**

1. **測試一律拆槳。** 手邊留著電源開關。
2. **第一次通電前確認電調中立位。** 雙向電調是 1500，單向是 1000。猜錯的話上電瞬間
   螺旋槳直接全速轉——這是唯一來不及斷電的情況。改 `firmware/ESP32/src/config.h`
   的 `ESC_US_NEUTRAL`，或現場用 `P neutral 1000` 改。
3. **電調和 ESP32 必須共地。**
4. **電調的 BEC 5V（紅線）不要接**，那是 5V，ESP32 的 GPIO 是 3.3V。

## 6. 比賽當天

**開機先發一條 `R`**，清掉實驗室留下來的 Wi-Fi 設定。

`P` 指令改過的 `ssid` / `pass` 會**永久**存在晶片裡，重新燒錄也不會清掉。不先清掉的話，
板子到了場地會悶頭去連家裡那個網路，連不上就是 Mission 1 直接零分，而且現場幾乎
想不到是這個原因。

連不上塔時**不要反覆重啟**，把重連間隔調大：

```
P wifiRetryMs 30000
```

家用路由器對短時間內反覆連線的裝置有防抖機制，越急越連不上。

## 7. 常見問題

| 現象 | 檢查 |
|---|---|
| 上電馬達就轉 | 電調中立位猜錯了。斷電，改 `ESC_US_NEUTRAL` |
| 推桿沒反應 | 還在 3 秒預熱內；或安全鍵沒解鎖；或序列埠斷流 |
| 只有一個馬達轉 | 另一路的訊號線或共地沒接好 |
| 馬達轉向相反 | 馬達線兩兩對調（無刷馬達任意對調兩根相線） |
| 左右轉方向反了 | 先跑 `--show-input` 確認軸符號，**先別改韌體** |
| 序列埠收到的行殘缺 | 埠被別的程式佔著（序列埠監視器、另一個 console） |
| 序列埠全是亂碼 | 鮑率不是 115200 |
| 燒錄後反覆重啟 | 有東西接到 GPIO33~37（PSRAM 佔用） |
| 攝影機開不起來 | 被 Teams / Zoom 佔著，先關掉 |
| `command not found: pio` | `~/.platformio/penv/bin/pio`（macOS）或裝 VS Code 擴充 |
| 找不到序列埠 | 只有一個埠插著時自動偵測一定找得到；兩個都插的話用 `--port` 指定 |

## 8. 還沒做的事

- 顏色辨識的 HSV 閾值還沒在真實泳池校準過，預設值只是起點
- 轉向方向與電調行程還沒在真船上驗證過
- 只有一個 Tag 在畫面裡測過；多個 Tag 同時出現的實景還沒試

```bash
cd host
python3 -m unittest test_console vision.test_apriltag vision.test_color -v
```

46 項，不需要攝影機、不需要板子、不需要手柄。涵蓋標籤偵測、多幀確認、游標取樣、
